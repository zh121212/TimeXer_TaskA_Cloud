# TimeXer研究：任务A云端训练代码包

当前状态：用户已授权上传云服务器，执行七模型五种子的完整训练、测试及水位对比作图；本地不执行正式训练。实时状态见运行记录。本包不管理其他工程的训练。

本轮只做任务A：输入淇河（镇平）与十二里河过去12步记录，预测十二里河30分钟后的闸前水位。先比较七个基线模型，每个模型五个随机种子；后续以TimeXer为基础改进。HPA只作对照，不再安排HPA消融。

先读：[任务流程与代码结构](05_实验文档/01_任务流程与代码结构.md)。模型细节见[七个模型说明](05_实验文档/02_模型与改进边界.md)，迁移步骤见[云端运行说明](05_实验文档/03_云端运行说明.md)。

## 唯一配置和唯一入口

- `04_实验配置/protocol.json`：唯一实验设置，包括任务、变量、窗口、模型、种子和训练参数。
- `run.py`：唯一入口，默认只显示状态，不会自动启动训练。
- 不需要V1、V2、其他仓库、Windows盘符、本机Conda目录、Node.js或表格插件。
- 本包没有复制本地权重、未完成任务、旧成绩或旧调度器，云端按同一协议重新训练。

## 当前确定的设置

- 模型：HPA、LSTM、MLP、Informer、TimeXer、iTransformer、TimeFilter。
- 五个种子：42、123、2024、2025、3407。种子是控制随机初始化和数据打乱的一组数字，用来检查训练波动。
- 上游与目标站均输入：闸前水位、闸后水位、水位差、瞬时流量和每孔实际开度历史；公共日历特征只加入一次。
- 日历特征：日内位置、星期位置、月内周次。
- 输入12步×17通道，输出下一步的一个闸前水位；12步是基准设置，尚未验证为最优。
- TimeXer、iTransformer通过独立时间输入保留日历原值；TimeFilter的日历列跳过窗口归一化，物理变量处理保持原样。
- 时间划分70%/10%/20%，标准化只用训练段。
- 每模型用种子42在三个学习率中按验证RMSE选参，再补齐另外四个种子。实际49次训练，最终报告35个模型与种子组合，不挑最好种子。
- 测试集在全部训练与选参完成后统一评估，生成按模型排列的同一张结果表。
- 指标：MAE、MAPE（百分数）、RMSE及相对保持不变预测的技能分数。水位单位m、流量m³/s、开度mm；MAPE遇到真实水位为0时记为空值，不用人为小数替代分母。
- 训练后自动生成黑色实测线、红色虚线预测的水位对比图。总览固定种子42，另外保存全部35组单次预测图；所有图使用完整测试段、相同时间范围和水位坐标尺度，不平滑、不按测试成绩挑选种子。

## 现在可以查看的命令

在项目根目录执行，以下三项不训练模型：

```bash
python run.py --stage plan
python run.py --stage audit
python run.py --stage prepare
```

`plan`只打印计划，`audit`检查原始数据，`prepare`生成训练／验证／测试数据包。数据打包不等于训练模型。

下面两条会训练模型，留到云端环境确认后再执行：

```bash
python run.py --stage smoke
python run.py --stage all
```

`smoke`是256条样本、2轮训练的小检查；`all`才执行完整选参、五种子训练和最终测试。重复运行完整命令时只复用同一版本的已完成记录，不覆盖失败或中断项。

云端本次运行已按用户要求增加 `parallel_train.py` 调度入口，最多同时训练2个不同的模型/种子组合。它只在Linux服务器接管现有队列：挂起原调度父进程，保留已经运行的子任务，复用已完成结果；新任务分别写入独立进度目录。原训练源码、模型、数据、随机种子及选参规则不变，代码校验值无需迁移。49项完成后恢复原队列，统一评估和画图。并行状态见 `03_实验结果/运行记录/parallel_status.json`，日志见 `parallel_train.log`；不要重复启动接管入口。

切换前后单次训练耗时受资源竞争影响，不能将这些混合耗时直接用于模型计算效率排名。

主结果为 `03_实验结果/01_对比实验/统一结果表.csv`，可用Excel直接打开：每模型五行单次结果、均值和标准差，共49行，再加一行保持不变参考，总计50行。它在正式评估完成后才生成，未完成的成绩不会填0。

预测图在 `03_实验结果/05_预测对比图/A/`，包含七模型横向总览和35组单次图，均提供PNG、PDF、SVG。横轴为从测试开始计算的天数，纵轴为水位m。逐时刻预测CSV保存在各运行目录，可据此重新作图。正式评估后执行 `python run.py --stage plot` 可只重画图片。
